# Характеристики и HP

Модуль `@deathwarriors/game-core/stats` меняет переданный `UnitState` непосредственно:

- `modifyStat(unit, stat, delta)` изменяет `maxHP`, `strength`, `agility`, `damage`, `movement` или `resistance`. Минимум maxHP — 1, остальных характеристик — 0.
- `modifyHP(unit, delta)` синхронно меняет HP в диапазоне `[0, maxHP]`, без сопротивления и события CELL_DAMAGE.
- `heal(unit, value)` восстанавливает HP до maxHP.

Рост maxHP не лечит, уменьшение обрезает HP. Возврат прежнего maxHP не возвращает утраченное здоровье. Снятие эффекта не имеет автоматического отката: обратное изменение требует отдельной операции контента. При насыщении нижней границы такая операция также работает над текущим значением, без скрытого накопления отрицательных модификаторов.

Операции возвращают `false` для зафиксированно погибшего юнита (`alive: false`), иначе `true`, включая изменение на 0. Они не фиксируют смерть и не освобождают клетку: это задача границы атомарного эффекта ENG-12. Поэтому последовательность `modifyHP(-100)`, `heal(1)` одного ещё живого владельца даёт 1 HP.

Технический контракт API: delta — конечное целое число; heal принимает неотрицательное конечное целое число, включая 0. Неверный аргумент или переполнение характеристики вызывает ошибку до изменения состояния. Это валидация контента, а не пропуск допустимой игровой операции. Отрицательное лечение не вводит альтернативный источник урона: для уменьшения HP используется modifyHP. Верхних игровых ограничений не добавлено; числа представлены обычным JavaScript number. Применение heal к неодушевлённым объектам остаётся OPEN и этим API не поддерживается.

Изменения сразу видны следующим расчётам; модуль не пересоздаёт очередь инициативы и не добавляет событий повышения maxHP.
