# Декларативные операции эффектов

create_damage_event из ENG-15 создаёт отложенное событие по семантической клетке контекста. Для него используется очередь домена damage; modify_hp остаётся отдельной синхронной операцией. Подробный контракт — в [домене damage](../damage/README.md).

add_damage_modifier из ENG-16 добавляет числовую запись по ID события либо damageEventId контекста атаки/защиты. Созданное внутри эффекта дополнительное событие не меняет этот контекстный ID. В очередь исполнения модификаторы не ставятся.

`@deathwarriors/game-core/operations` связывает очередь, фазовые снимки, селекторы, характеристики и постоянные экземпляры эффектов. Runtime содержит world и effects. `schedulePhase` прикрепляет независимый контекст к снимкам, `createOperationQueue` исполняет их. Проверку жизни владельца и afterEffect передаёт планировщик; полная фиксация смерти остаётся в ENG-12. Фазы вызываются внешним планировщиком в положенный момент.

Поддержаны операции modify_stat, modify_hp, heal, add_effect, remove_effect и modify_counter. У операций по сущностям есть target из модуля селекторов. Изменения HP/характеристик и лечение применяются только к живым юнитам; alive=true при HP=0 допускает последующее лечение того же эффекта. modify_hp не создаёт CELL_DAMAGE и не вычитает сопротивление.

add_effect принимает definitionId, phase, operations и state, а владельцем нового экземпляра делает выбранную сущность. Поддержаны живой юнит, существующая ловушка и неразрушенный проём. Стены/препятствия и погибшие юниты пропускаются. Добавление не выполняет операции нового экземпляра: для немедленного усиления родитель должен отдельно изменить характеристику. Новое наложение всегда создаёт независимый экземпляр.

remove_effect и modify_counter адресуют self (постоянный оригинал текущей копии) либо instance с конкретным id. Снятие оригинала не отменяет текущую копию и не откатывает её операции. Отсутствующие оригинал/счётчик пропускаются. Удаление, сроки жизни и обратные операции не выполняются автоматически.

Числовое выражение — число либо объект с kind:

- stat: target и stat читают текущую характеристику ровно одного выбранного юнита;
- state: name читает числовое поле состояния запланированной копии;
- counter: instance и name читают актуальное числовое поле постоянного оригинала;
- add, subtract, multiply, min, max: left и right содержат вложенные выражения.

Нет eval, JS-обработчиков из контент-пака, агрегирования массовых наборов или неявного преобразования отсутствующего значения в 0. Недоступный адресат/параметр пропускает только соответствующую операцию. Массовые цели обрабатываются в порядке селектора, параметры вычисляются перед применением к очередной цели из текущего состояния. Неосуществимые элементы пропускаются отдельно. Ошибочный формат или недопустимое число — ошибка контента; как и ранее, исключение останавливает очередь без отката уже выполненного. Полная проверка недоверенного пака относится к ENG-31.

Конвенции этой минимальной грамматики фиксируются в ENG-11. `place_entity` с семантической
целью `cell` и шаблоном сущности подключён доменом `summoning` (ENG-29); для очередей нужен
сохраняемый `runtime.summoning`. Условные блоки, вероятностные действия и перемещение
подключаются в соответствующих задачах. Контексты этапов передаёт планировщик;
schedulePhase проверяет владельца, но не запускает фазы самостоятельно.

## Наблюдение операций

Необязательный `OperationRuntime.observer` получает `before` и `after` каждой операции
с её эффектом и признаком `applied`. Наблюдение не является игровым эффектом и не должно
менять мир. Оно позволяет журналу видеть отдельные изменения HP внутри атомарного эффекта.

## Боевые реакции

Операция trigger_reaction копирует боевой стек target с сохранением исходного контекста.
Она поддержана обычной очередью операций и очередью CELL_DAMAGE; cause содержит только
причинных предков, а definitionId текущей способности добавляется на время исполнения.
Постоянный экземпляр не меняется. Сервисы OperationEvents необязательны по типу; операция,
которой необходим отсутствующий сервис, явно сообщает об ошибке конфигурации.
