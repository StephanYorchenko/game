# Цели защитника и пригодность дверей

`@deathwarriors/game-core/defender-targeting` принимает мир, ID защитника и явный список
известных ему врагов. Неизвестные, погибшие и наружные враги исключаются. Известность
внутри здания задаёт сценарий/вызывающий AI; новая система зрения не вводится.
Границы читаются из `cell.area`, включая дверные позиции: модуль не угадывает их по стенам.

`assessDefenderTargets` не расходует RNG и не меняет мир. Если до атакующей позиции хотя
бы одного известного врага есть открытый путь, возвращаются эти враги с длиной пути,
а все двери получают FALSE. Геометрически близкий враг за закрытой дверью не перехватывает
приоритет у более далёкого достижимого. Проверка используется после выбора немедленной атаки.

Без открытых путей для каждой закрытой неукреплённой внутренней двери вычисляется только
`leadsToEnemy`. Поисковая копия карты постепенно открывает двери, до которых уже доступно
взаимодействие по их матрице и supercover. Сохраняются направления движения, блокирующие
структуры, укрепления, окна, тела юнитов, известные ловушки и внутренняя область.
Потенциальный путь может включать несколько открываемых дверей. Сам мир не открывается.

TRUE требует простого пути через дверь к атакующей позиции: две ветви пути не могут
повторно пройти общий участок, превращая дверь в тупиковую вылазку. Для односторонних
направлений отдельно учитываются входы/выходы компоненты. Внутри обратимой компоненты
проверяются две непересекающиеся ветви с единичной пропускной способностью клеток.
Полный перебор всех маршрутов не используется. Открытие линии выстрела через дверь тоже
даёт TRUE, даже если после открытия стрелку не нужно пересекать сам проём.

`distance` двери — только открытый путь до её позиции взаимодействия, либо null, если
сейчас ещё нужно открыть другую дверь. Длина дороги за дверью не вычисляется и не ранжирует
кандидатов. `selectDefenderDestination` выбирает ближайшего доступного врага либо ближайшую
TRUE-дверь для подхода, затем кратчайший путь через существующий pathfinding. Равенства
разрешаются seeded RNG; стабильный порядок — юниты мира и клетки карты по строкам.
Несколько уже доступных TRUE-дверей имеют дистанцию 0 и равные шансы независимо от дороги за ними.

`isDefenderDoorEligible` можно передать как проверку `defenderCanOpen` в домен openings.
Тот повторно проверяет текущую геометрию INTERACT. При отсутствии вариантов возвращается
`none/blocked`: выбор частично заблокированного маршрута и точки ожидания остаётся OPEN.
Модуль не создаёт ATTACK/INTERACT/MOVE и не переносит эти правила на врагов.
