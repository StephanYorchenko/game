# Выбор и исполнение обычных действий

Публичный вход — `@deathwarriors/game-core/actions`.

`chooseAutomaticAction(world, actorId, rng, options?)` возвращает JSON DTO:
ATTACK с видом/ID цели, INTERACT с ID проёма либо MOVE с целью маршрута/null.
Приоритет всегда ATTACK → допустимый INTERACT → MOVE. Выбор использует существующие
правила доменов combat/openings; мир при выборе не меняется.

Защитник видит только `knownEnemyIds`, при открытом пути предпочитает ближайшего
известного внутреннего противника, иначе рассматривает TRUE-двери. Враг сравнивает
самостоятельные проёмы и защитников по длине допустимого пути до нужного действия.
Равные ближайшие цели всех типов имеют равные шансы. Сам маршрут на этой стадии
не разыгрывается: шаги запросит executeMove. Нулевая скорость без доступных ATTACK/INTERACT
создаёт MOVE без цели и без выбора ненужного маршрута через RNG.

`executeAutomaticAction(runtime, actorId, action, queue, rng, getOptions?)` совместим
с ленивым исполнителем хода. ATTACK разрешает обычные фазы и независимый урон, INTERACT
синхронно открывает один повторно проверенный проём между пакетами очереди, MOVE выдаёт
по одному эффекту шага. Перед началом предыдущая очередь должна быть полностью разрешена.
Невозможное выбранное действие не заменяется другим действием внутри того же слота.

`runAutomaticTurn(runtime, actorId, getTurnOrder, damage, rng, options?)` связывает выбор
с runUnitTurn. Каждый слот выбирается после своей ACTION_START и всех предыдущих последствий.
Открытие двери не завершает ход; MOVE штатно заканчивается перед доступной атакой,
а следующий слот может стать ATTACK. MOVE с 0 шагов расходует слот и вызывает ACTION_END.
Прерывания и смерть обрабатывает общий исполнитель; дополнительных слотов и WAIT нет.

`getOptions()` читает актуальные знания и ограничения. Переданный DamageState сохраняет
сквозные ID независимых событий. Необязательная `createQueue(controlledRuntime)` подключает
совместимую AttackQueue, например createJournalDamageQueue. Наблюдатели onAction/onPhase
предназначены для журнала и диагностики и не должны менять симуляцию.

Частичные пути к точке ожидания и автоматическая смена цели при блокаде остаются OPEN.
При отсутствии полного маршрута MOVE содержит 0 шагов. Ночь из 13 раундов и обнаружение
ловушек — отдельные задачи; в этом домене нет собственных правил знания или баланса.
