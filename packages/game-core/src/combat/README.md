# Обычная атака

`@deathwarriors/game-core/combat` проверяет одну выбранную пару юнитов и разрешает её
через уже существующую очередь `DamageQueue`. Выбор цели относится к AI.
`checkUnitAttack` проверяет жизнь, размещение, разные стороны, маску атакующего и supercover.
Защитник не атакует наружу. Базовая реализация работает из внутренней области; атаки врага
снаружи внутрь остаются OPEN и здесь не включены. Известность цели проверяет вызывающий AI,
новая система зрения не вводится. Исключения перекрытия линии передаются через `line`.

`resolveUnitAttack` вызывается после полного разрешения ACTION_START, между пакетами
той же очереди. Броски идут в порядке атакующий → защищающийся. Успех только при
`d6 + strength > d6 + agility`; ничья — защита. При неосуществимой атаке нет бросков,
эффектов и новых ID. При промахе исполняются ATTACK_FAILURE → DEFENSE_SUCCESS без базового урона.

При успехе очередь заранее резервирует CELL_DAMAGE и его стопку модификаторов, включая
базовый урон 0. Клетка и базовый damage фиксируются до эффектов; ID получают оба контекста.
Далее полностью разрешается ATTACK_SUCCESS, затем берётся актуальный снимок DEFENSE_FAILURE,
затем исполняется независимый CELL_DAMAGE. Последствия каждой фазы проходят в общей очереди.
Смерть защищающегося отменяет его обычную фазу; смерть атакующего не отменяет уже созданный урон.
Урон получает нынешний обитатель исходной клетки с текущим сопротивлением.
Изменения damage в фазах не переписывают исходное событие: для этого есть модификаторы.

Для подключения к `runUnitTurn` создайте одну DamageQueue и передайте её как `createQueue`;
в обработчике ATTACK вызовите `resolveUnitAttack` с той же очередью. Вызов синхронный,
не создаёт отдельного слота и не вызывает ACTION_START/ACTION_END повторно.
`createJournalDamageQueue` сохраняет метод резервирования события. `onOutcome` позволяет
записать исход, ID и броски в журнал; обёрнутый RNG отдельно фиксирует расход случайности.
JSON-результат атаки описывает исход бросков, а не итоговую потерю HP (её сообщает DamageOutcome).

Расчёт укреплений, контратаки и автоматический выбор цели подключаются отдельными задачами.
