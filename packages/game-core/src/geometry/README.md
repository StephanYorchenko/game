# Геометрия масок

`@deathwarriors/game-core/geometry` содержит общую геометрию атаки и взаимодействия. `canReachMaskedCell` проверяет фиксированную маску 5×5 с центром на атакующем. `canReachInteraction` использует отдельную матрицу объекта: её центр — клетка объекта, единицы задают допустимые позиции юнита вокруг него. Это техническая конвенция для асимметричных матриц; вращений и направления взгляда нет.

`getSupercoverCells` проводит отрезок между центрами клеток в пределах радиуса маски (по две клетки в каждую сторону). При точном касании угла учитываются обе боковые клетки и диагональная клетка. Любой из двух боковых блокеров закрывает линию: стрелять сквозь угол нельзя. Сравнение пересечений целочисленное, без epsilon. В возвращаемом порядке при угловом касании сначала идёт боковая клетка по X, затем по Y; это порядок обхода, а не игровой приоритет.

`hasClearLine` проверяет промежуточные клетки. Стены, закрытые двери/окна, препятствия с blocksAttack и любые юниты блокируют линию; ловушки и blocksMovement сами по себе её не закрывают. Открытые/разрушенные проёмы не блокируют, но стоящий в них юнит блокирует. Начальная и целевая клетки исключены из проверки блокеров: укреплённая дверь и сам атакуемый юнит не закрывают линию к себе. Законность типа цели, её жизнь, видимость и правила сторон проверяет целеполагание, а не этот модуль.

`LineOptions.ignoresBlocker` позволяет вызывающему слою разрешить конкретные исключения ключевых слов. На клетке с проёмом и юнитом исключение для одного не снимает блокировку другого. Вне карты и вне радиуса 5×5 доступности нет. Функции не меняют мир и не используют RNG.

Граничная конвенция supercover и центр матрицы взаимодействия описаны здесь для ревью ENG-05. Это не расширение списка целей или действий.
