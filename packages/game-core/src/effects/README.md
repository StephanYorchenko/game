# Фазовые стеки и снимки

`@deathwarriors/game-core/effects` хранит локальные экземпляры эффектов в JSON-данных `EffectStore`. У экземпляра один владелец, одно определение и одна фаза из EFFECT_PHASES. Массив instances хранит порядок добавления от старого к новому; snapshotPhase выбирает владельца/фазу и возвращает новые → старые. Переупорядочивания, слияния одинаковых определений и автоматического удаления нет.

`addEffect` копирует определение, операции и состояние, создаёт новый `effect:N` и возвращает instanceId. Счётчик nextInstanceId хранится вместе с экземплярами: удалённые ID не переиспользуются. Хранилище одно на симуляцию; не создавать его заново при переходе фазы, ночи или кампании. Оно отделено от геометрического WorldState v1; объединённый снимок симуляции подключается в задаче API/сохранения. Произвольный недоверенный контент должен пройти загрузчик контент-пака ENG-31.

`snapshotPhase` создаёт глубокую копию JSON-операций и состояния каждого экземпляра. Последующее добавление ждёт следующего снимка, удаление оригинала не отменяет готовую копию, изменения оригинала и копии не синхронизируются. Исполнение не изменяет постоянный счётчик автоматически. Для передачи в очередь используется `queue.enqueue(...snapshotPhase(...))`, из исполняемого эффекта — `context.emit(...)`.

Очередь получила необязательный второй параметр типа `ExecutionQueue<Operation, ScheduledEffect<Operation>>`, чтобы обработчик видел instanceId, фазу и состояние копии. Прежний API очереди совместим; порядок исполнения не изменён. Только снимок DEATH получает source=death — исключение из проверки жизни относится к собственному стеку смерти владельца.

`modifyEffectCounter(store, instanceId, name, delta)` явно меняет целочисленное поле верхнего уровня state у постоянного экземпляра. Удалённый оригинал, отсутствующее поле или поле другого типа дают false: невозможная операция пропускается, новый экземпляр/счётчик не создаётся. Это техническая политика для оставшегося OPEN. Счётчик может уйти ниже нуля: условия и явное удаление задаёт контент, скрытого срока жизни и нижнего предела нет. Снятие через removeEffect не выполняет обратные операции характеристик.

Неверные аргументы, не-JSON значения и циклы отклоняются до добавления экземпляра. Грамматика операций и выражений, условия фаз, семантические клетки, полная загрузка контента и удаление владельца относятся к следующим задачам; здесь операции — типизированные JSON-данные без выполнения произвольного JS.
