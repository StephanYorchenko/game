# Модель состояния

`loadWorld(input)` принимает неизвестные данные, проверяет схему версии 1 и возвращает собственную копию `WorldState`. `parseWorld(json)` делает то же для JSON-строки. Ошибка `ScenarioValidationError` содержит адрес поля в `path`.

- `map.cells` — плотный массив по строкам: `y * width + x`. Клетка хранит поверхность, принадлежность внутренней/внешней области и фиксированную структуру (стену, препятствие, дверь или окно).
- `units` и `traps` — размещённые сущности с координатами. В клетке не бывает двух таких сущностей. Стена, блокирующее движение препятствие и закрытый проём не могут содержать размещённую сущность.
- Структуры — постоянный слой карты. Открытый/разрушенный проём сохраняет ID и свойства, пока по его клетке проходит юнит; это не вторая размещённая сущность.
- ID уникальны среди всех структур, юнитов и ловушек. `definitionId` ссылается на определение контента; наличие этого определения будет проверяться загрузчиком контент-пака в ENG-31.
- `alive` хранится отдельно от HP: нулевой HP внутри ещё исполняемого атомарного эффекта не фиксирует смерть. Зафиксированно погибший юнит имеет `position: null`, `hp: 0` и больше не занимает клетку. Сам переход в смерть реализуется в ENG-12.
- Матрицы атаки и взаимодействия — бинарные 5×5. Характеристики — неотрицательные целые числа, `maxHP >= 1`, `hp <= maxHP`. Загрузчик отклоняет ошибки, а не исправляет их молча.

`getCell(map, position)` возвращает клетку или `undefined` за границами карты. `getOccupant(world, position)` находит размещённую сущность. `serializeWorld(world)` сохраняет текущее состояние в JSON; для корректного состояния `parseWorld(serializeWorld(world))` сохраняет все данные.

Классов UI, `Map`/`Set`, методов или ссылок на ассеты в состоянии нет. Поиск пути, геометрия, интерпретация ключевых слов, бой и эффекты не входят в загрузчик. Области здания задаются входной картой явно; выводить границу из расположения стен загрузчик не пытается.
