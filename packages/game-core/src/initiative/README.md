# Инициатива начала ночи

`createInitiativeOrder(units, rng)` из `@deathwarriors/game-core/initiative` берёт живых размещённых участников и возвращает самостоятельный снимок очереди. Всем сначала бросается d6 в порядке входного массива (в обычной симуляции — WorldState.units). Порядок сортировки: d6 + текущая ловкость по убыванию, затем сама текущая ловкость по убыванию.

Техническая конвенция повторных ничьих: только группы с равными обоими значениями делают дополнительный d6 каждому участнику. Больший дополнительный бросок идёт раньше. Если внутри группы снова есть ничья, перебрасывается только соответствующая подгруппа; ранее разрешённый порядок сохраняется. Подгруппы разрешаются от старших к младшим, вложенная ничья завершается перед переходом к следующей группе. Внутри ещё равной группы броски идут в исходном порядке участников. Случайность никогда не вызывается из компаратора сортировки.

Повторяем до разрешения ничьей, без скрытого перехода к ID или порядку сторон после некоторого числа попыток. Реализация итеративная: длинная цепочка повторных ничьих не наращивает стек вызовов. Пустой набор не расходует RNG; единственный участник всё равно получает обычный начальный бросок d6, как требует правило начала ночи. Участников разных сторон не разделяем.

Запись сохраняет unitId, исходный roll, agility, initiative и историю tieRolls. Изменение характеристик юнита после создания очереди не меняет её позиции и сохранённые значения. Это не запрещает будущим специальным операциям менять очередь, но автоматической пересортировки здесь нет. Призыв и вставки во время ночи относятся к отдельной задаче ENG-29.

Входные юниты не меняются. Повторные ID и некорректная ловкость отклоняются до расхода RNG. Числа используют обычный JavaScript number, как существующая модель характеристик; источник d6 должен соблюдать диапазон 1..6. Формирование очереди предполагает завершённую фиксацию смерти на границе перед началом ночи и не выполняет её самостоятельно.
