# Минимальный пакет контента

`@deathwarriors/game-core/content` предоставляет `loadContentPack(unknown)` и
`compileContentPack(unknown)`. Загрузчик возвращает независимую JSON-копию определений;
ошибка `ContentValidationError.path` указывает точное поле. Ни загрузка, ни компиляция
не создают экземпляры, не меняют мир и не расходуют RNG.

Формат v1: `version`, `id`, массивы `units`, `traps`, `openings`, `effects`.
У определений общий уникальный `definitionId`; префикс `engine:` зарезервирован для
внутренних эффектов. ID экземпляра, координаты, текущая очередь и состояние runtime
в каталог не входят. У сущностей и проёмов `effectIds` ссылаются на определения эффектов.
Юнит задаёт сторону, характеристики, фиксированную маску атаки и ключевые слова;
проём — вид, матрицу взаимодействия и укрепление либо null. Состояние открытости
и ID проёма назначает конкретный сценарий.

Поддержаны операции текущего runtime, кроме внутреннего `move_step`. Отличия формата:
`add_effect` задаёт `effectId`, `place_entity` — `definitionId` юнита/ловушки.
Компилятор разворачивает эти ссылки в собственные inline-шаблоны существующих операций.
Циклы такого разворачивания отклоняются с адресом ссылки: это ограничение текущего
inline-представления, а не новое правило реакций или игровой длительности способностей.

Проверяются неизвестные/пропущенные поля, JSON-типы, конечность чисел, целые характеристики,
HP/maxHP, маски 5×5, фазы, селекторы, формулы, операции и типы ссылок. `on_damaged` и JS/eval
не поддерживаются. Адреса runtime (`unit.id`, `instance.id`, ID события урона) проверяются
по форме; существование адресата проверяет исполнитель по актуальному состоянию. Значение
динамической формулы окончательно проверяет соответствующая операция при исполнении.

`CompiledContentPack.entities` содержит `EntityTemplate` для `placeEntity` и призыва,
`effects` — `EffectTemplate`, `openings` — определения проёмов с развёрнутыми эффектами.
Граф ссылок не разделяет изменяемое состояние между копиями шаблонов или с исходным JSON.

## Исполняемый пример

`minimal.json` содержит бойца, лучника с дальней маской, врага, дверь, окно, укреплённую дверь,
ловушку, кровотечение и временную скорость. Числа — тестовые значения контентного примера;
утверждённые правила баланса они не задают. DEATH ловушки создаёт CELL_DAMAGE и накладывает
кровотечение на `occupant`; кровотечение меняет HP в TURN_START.

Скорость явно увеличивается в ACTION_START, туда же регистрируется отдельный эффект отката.
В ACTION_END он уменьшает скорость и удаляет себя. Пример не вводит автоматический откат
при смерти: завершающие фазы погибшего сохраняют согласованные правила.

`content.test.mjs` исполняет пример через публичные API размещения, очереди и хода без браузера;
проверяет урон, следующий тик кровотечения, откат скорости и ошибки загрузки. Ассеты,
редактор, генерация сценариев и полноценная симуляция ночи остаются отдельными задачами.
