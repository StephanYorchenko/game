# Проходимость

`canEnterCell(world, unit, position, options)` проверяет саму клетку, `canStep` дополнительно требует один ортогональный шаг из текущей позиции. `getStepDestinations` использует ту же проверку и возвращает допустимых соседей в порядке север, восток, юг, запад. Эти функции не меняют состояние и не расходуют RNG.

Ограничения ключевых слов передаются через `MovementOptions`: `directions` ограничивает направления (пустой массив запрещает движение), `allowWindows: false` запрещает оконные клетки независимо от состояния проёма. Имена ключевых слов и классов внутри модуля не интерпретируются: например, ограничения «Гиганта» разрешает вызывающий слой контента.

Для защитников все ловушки известны, внешние клетки запрещены. Для врага список `knownTrapIds` индивидуален; неизвестная ловушка допускается в маршрут. При реальном входе её сначала уничтожает атомарный шаг ENG-25, поэтому две размещённые сущности не сосуществуют. Любой другой юнит блокирует клетку независимо от стороны.

Закрытый проём непроходим до отдельного действия открытия/разрушения. Скорость, оставшиеся шаги и принудительное перемещение не относятся к этой проверке обычного шага: их обрабатывает исполнитель действия. Граница здания берётся из явного `area` клетки, без вывода по соседним стенам.
