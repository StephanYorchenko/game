# Селекторы и контекст

`@deathwarriors/game-core/targets` разрешает owner, attacker, defender, unit по ID, allies, enemies и семантическую cell. Геометрического областного селектора и координат в самом селекторе cell нет.

`createPhaseContext` копирует и замораживает координаты в момент события: attack — выбранная клетка атаки; death — клетка смерти; move_end — клетка старта всего MOVE, которую исполнитель сохраняет при его начале. Обычная phase не предоставляет клетку или участников атаки. Перемещение/смерть участников после создания контекста не меняет зафиксированную клетку. Контекст содержит только JSON-данные и может копироваться вместе с запланированным эффектом; поля контекста подключаются планировщиком фаз, а не вычисляются из текущей позиции при резолве.

`resolveTargets` возвращает entities, cell либо unavailable с причиной. Сущности разрешаются по текущему миру, а координата берётся из снимка контекста. owner/attacker/defender могут адресовать юнита, ловушку или структуру; selector unit адресует именно юнита. Возвращаются ссылки на актуальные сущности для последующих операций; результат разрешения не является сохраняемым снимком.

Операция, требующая живого юнита (например heal), передаёт livingUnitsOnly=true. Проверяется alive, а не hp>0: временное нулевое HP внутри эффекта не означает зафиксированную смерть. Клетка остаётся допустимым адресом независимо от этой настройки, в том числе когда пуста или занята: осуществимость размещения проверяется отдельной операцией непосредственно при исполнении.

Массовые селекторы возвращают юнитов на карте в порядке WorldState.units. allies включает самого владельца, если он стоит на карте; это техническая конвенция, отдельное исключение себя не вводится. При фильтрации живых погибшие элементы исключаются отдельно, остальные сохраняются. Для владельца без стороны (ловушка/структура) allies/enemies дают owner_has_no_side: сторона нейтрального объекта остаётся OPEN, приписывать её молча нельзя.

Отсутствующие контекст/сущность и клетка вне карты возвращают явный unavailable; исполнитель пропускает соответствующую операцию по правилу 88. Пустой набор массовой выборки — entities с пустым массивом. Нет автоматического выбора другой клетки или сущности. Дополнительные правила жизни неодушевлённых объектов и их командная принадлежность уточняются при подключении соответствующих операций.
